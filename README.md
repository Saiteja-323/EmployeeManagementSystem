# Employee Management System

## Project Overview

Employee Management System is a MySQL-based database project designed to manage employee, department, and project information efficiently.

The project demonstrates relational database design and various SQL concepts used for data management, analysis, and transaction control.

## Database Tables

The project contains three main tables:

- departments
- employees
- projects

## Relationships

- One department can have many employees.
- One department can have many projects.
- Employees have a self-referencing manager relationship using manager_id.
